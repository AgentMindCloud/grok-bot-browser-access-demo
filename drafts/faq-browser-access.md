## Can I use Grok Bot from a browser without installing the app?

No. There is no Grok Bot browser client today. [grok.com](https://grok.com) is Grok chat, a different product, and it does not list your bots.

Grok Bot is included with **Cursor Pro**, **Pro+**, **Ultra**, and self-serve **Teams**, and with a linked **SuperGrok**, **SuperGrok Plus**, or **SuperGrok Heavy** subscription. A Cursor plan already covers it. Buying SuperGrok is not required. Current help also includes an **X Premium+** link on the same list.

### What to do on a computer where you cannot install the app

Use the Grok Bot app on your phone and sign in with the same Cursor account. That does not install anything on this computer. The phone app opens the same bots, conversations, routines, and cloud computer.

- iPhone and iPad: [App Store](https://apps.apple.com/app/id6794501026)
- Android: [Google Play](https://play.google.com/store/apps/details?id=ai.x.grok.bot)
- Setup steps: [Grok Bot on mobile](https://cursor.com/help/grok-bot/mobile) and [Grok Bot for Mobile](https://docs.x.ai/grok-bot/mobile)

### What works there

You can message a bot, dictate, start a voice chat, approve a step, and pick up routines. Existing users go to the synced bot list after they sign in with the account that already has Grok Bot.

### What does not work

- There is no bot list in the Grok web app, and signing in there does not open Grok Bot.
- Updating, recovering, or resetting the bot computer is still desktop-only. Do that from a machine where the desktop app is already allowed. It is not required just to read and message your bots from the phone.
